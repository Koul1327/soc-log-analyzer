# SOC Log Analyzer

Учебный CLI-анализатор SSH-журналов на Python

Читает JSON-выгрузку journalctl, извлекает события аутентификации и обнаруживает серии неудачных входов.

## Текущее состояние

- Реализовано первое правило SOC001: заданное число неудачныз входов с одного IP в один аккаунт за заданный промежуток времени.
- Поддерживается выбор файла, порога и временного отрезка
- Некорректный JSON, записи неподходящего типа и нетекстовое поле MESSAGE пропускаются в предупреждением
- 5 автоматических тестов
- Проверенно на собственном Ubuntu Server с SSH и Fail2Ban

## Подготовка

Проверенно с Python 3.12 на Ubuntu WSL
Команды выполняются из корня репозитория

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install pytest
```

Для самого анализатора достаточно стандартной библиотеки Python
pytest нужен для тестов

## Запуск демонстрации

```bash
PYTHONPATH=src python3 inspect_ssh.py --file samples/ssh_demo.jsonl --threshold 2 --window 300
```

Пример содержит две искусственные неудачные попытки с интервалом 60 секунд, ожидается предупреждение SOC001

Параметры:

- --file - путь к JSON-выгрузке journalctl
- --threshold - минимальное количество неудач, по умолчанию 5
- --window - временной отрезок в секундах, по умолчанию 300

## Тесты

```bash
PYTHONPATH=src python3 -m pytest tests/ -q
```

## Ограничения

Это прототип а не готовая SIEM

- Обрабатывает сохраненный файл, а не поток событий
- Для подсчета неудач использует сообщения Failed password
- Возвращает первую подходящую серию для каждой пары IP и аккаунта
- Обработка поврежденных полей времени и нестандартных SSH-сообщений пока не завершена
- Срабатывание правила требует проверки аналитиком и само по себе не доказывает аттаку!

Настоящие журналы стенда не включены в репозиторий
